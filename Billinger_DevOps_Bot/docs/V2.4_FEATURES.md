# Billinger Bot v2.6.0 Feature Guide

## Unified operating model

The release integrates the full learning institute and career workflow into one local application:

1. Learn from the verified tool library.
2. Complete practice, tests, company tickets, incidents, practical exams, and capstones.
3. Collect approved evidence in the portfolio register.
4. Generate a labelled DevOps portfolio website, PDF, and repository package.
5. Maintain a verified candidate profile and master resume source.
6. Discover or paste jobs and receive an explainable suitability score.
7. Tailor the resume and portfolio using only verified information.
8. Preview an email with the exact recipient and attachments.
9. Approve assisted submission or send through Gmail OAuth.
10. Track the application and prepare a job-specific end-to-end mock interview.

## Job discovery

Supported sources are Greenhouse board tokens, Lever site tokens, public HTTPS RSS feeds, and public HTTPS careers pages that permit access. The scanner validates public destinations, respects robots directives for generic career pages, limits response size, blocks private/local network targets, and does not bypass authentication or anti-bot controls.

## Explainable job matching

The matching report separates technical skills, experience, role/seniority, preferred requirements, project evidence, location, education/certification, and preference compatibility. It lists matched and missing requirements and explicitly warns that missing skills are not added to the resume.

## Portfolio builder

Each portfolio project records its origin: independent project, guided course project, simulated company assignment, practical assessment, or verified professional work. Projects are scored for correctness, documentation, evidence, security, observability, rollback, business explanation, and presentation. Possible secrets block publication.

Outputs include:

- Static recruiter website
- Recruiter PDF
- GitHub-ready ZIP with project README files
- Job-specific project ordering
- Resume-ready selected-project bullets

## Resume and email application

The tailored resume is exported as PDF, DOCX, HTML, and TXT. The master profile remains unchanged. The application-email workflow validates the recipient, blocks header injection, confirms file ownership, creates an EML preview, and requires explicit approval before Gmail send.

## Application tracking and interview preparation

Applications track discovered, recommended, prepared, awaiting approval, applied, follow-up, recruiter response, assessment, interview, rejected, offer, and closed states. Interview preparation combines the exact job description, verified candidate profile, selected portfolio evidence, and clearly labelled public company research into a nine-round preparation pack.

## Not included by design

- Blind mass application
- CAPTCHA bypass
- Automated login circumvention
- Fabricated resume experience
- Silent email sending
- Unrestricted web scraping
- Secret or credential publication
