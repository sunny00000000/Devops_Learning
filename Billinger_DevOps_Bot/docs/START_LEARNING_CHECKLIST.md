# Start Learning Checklist

Complete this once for the active learner:

- [ ] Extract v2.7 into a new folder.
- [ ] Start with `Start_Billinger_Bot.bat`.
- [ ] Confirm the badge says `4K precision build 2.9.0`.
- [ ] Configure the administrator PIN.
- [ ] Select a target role and daily study time.
- [ ] Complete the 20-question baseline.
- [ ] Confirm the verified learning library is visible.
- [ ] Run the optional safe environment scan.
- [ ] Test at least one AI provider, or deliberately continue in local-only mode.
- [ ] Use the fallback dry run when more than one provider is configured.
- [ ] Create a full backup.
- [ ] Verify the backup health result.
- [ ] Generate today’s learning plan.
- [ ] Open the recommended first tool.
- [ ] Complete one lesson, one lab, one test, and one interview sample.
- [ ] Restart the bot and confirm progress remains saved.

After this checklist passes, freeze feature changes during the first 30 days of learning and record real issues in a learner feedback log.
