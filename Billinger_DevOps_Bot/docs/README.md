# Billinger — Enterprise DevOps & Cloud Career Platform v3.0.0

Billinger is an institutional-grade, privacy-first, local DevOps learning, hands-on practice, virtual incident triage, and career launchpad.

## Key Features
- **12 Comprehensive DevOps Domains:** Linux SysAdmin, Git, Bash, Python SRE, Docker, Kubernetes, Terraform, Ansible, CI/CD, Prometheus/Grafana, AWS, and Enterprise SRE.
- **Command Playground:** Safe sandboxed execution with automated mistake detection.
- **Production Incident Center:** Real-time on-call triage simulator measuring MTTR.
- **Personal Learning Twin:** Multi-factor skill radar tracking 8 dimensions of production readiness.
- **Document Vault:** Zero cross-contamination document ingestion and semantic search.
- **Multi-Provider AI & Offline Mode:** Intelligent workload router supporting Gemini, Groq, OpenAI, and OpenRouter.

## Quick Launch
### Windows
Run `Start_Billinger_Bot.bat`

### Linux
Run `./start_billinger.sh`

### Run Verification Tests
```bash
python3 tests/run_tests.py
```
