# Billinger Bot v2.3.0 Feature Guide

## Administrator Control Deck

The administrator portal is local-only and protected by a PIN. It provides:

- Institute and administrator identity.
- All-student performance summary.
- Student target-role, study-time, and interview-date settings.
- Batch creation, membership, deadlines, and role/level targeting.
- Batch assignments and announcements.
- Verified learning-library import and publishing.
- Certificate issuing and verification.
- CSV report export.
- Full backup creation and download.
- Restore and offline update staging.

Administrator sessions expire after eight hours or when the application closes.

## Personal learning day

The daily planner combines the selected target role, available study time, learning progress, weak tools, prerequisites, and current batch work. It provides a manageable sequence of reading, practice, assessment, revision, and interview activities.

## Dependency roadmap

The roadmap represents 21 tools and their prerequisite relationships. It identifies completed foundations, current recommendations, and blocked advanced domains. The roadmap guides learners but does not permanently prevent an administrator from assigning required work.

## Practical Examination Arena

There are 84 templates: one for each of 21 tools at Beginner, Intermediate, Advanced, and Master levels. Each run records start time, time allowance, response, score, pass status, and review dimensions. Scoring looks for:

- Technical reasoning and implementation detail.
- Diagnostic structure and root-cause hypothesis.
- Evidence and validation.
- Security and least privilege.
- Backup and rollback.
- Stakeholder communication.
- Business-impact awareness.

The practical engine evaluates a written implementation and evidence plan. It does not claim to execute every vendor tool or replace instructor review.

## Student project workspace

Every student receives an isolated local folder. Text files can be created in the dashboard, and supported evidence files can be uploaded. Path traversal and access outside the student directory are blocked.

## Verified content importer

Imports are staged rather than automatically published. The importer groups PDF/DOCX pairs, extracts available text, proposes a primary tool, records confidence, and waits for administrator approval. The final tool, title, level, and collection are controlled by the administrator.

## Certificates

Certificates are local HTML files with a unique verification code stored in SQLite. The verification page checks the code against the local database. Certificates should be issued only after an instructor reviews the learner’s evidence.

## Backup, restore, and offline updates

A full backup contains the SQLite database, student workspaces, certificates, resumes, and labs. Restore and update packages are only staged while the server is running. The administrator then closes the bot and runs the corresponding maintenance batch file, which makes a safety copy before applying changes.

## 3D/VFX interface

The visual layer uses modern CSS transforms, gradients, translucent panels, animated perspective elements, and pointer-based card tilt. It includes a reduced-motion mode and remains fully usable without animation. It intentionally avoids Electron, game engines, bundled videos, and heavy graphics libraries.
