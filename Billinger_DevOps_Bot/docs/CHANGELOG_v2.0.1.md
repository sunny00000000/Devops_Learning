# Billinger DevOps Learning Bot v2.0.1

Release date: 2026-08-01

## Fixed

- Left navigation could not scroll when its content exceeded the browser viewport.
- Narrow-screen navigation labels could be clipped and required browser zoom.

## Added

- Independent sidebar scrolling on desktop and mobile.
- Dynamic mobile viewport-height support.
- Searchable Command & Scenario Coverage page.
- Exact content manifest API at `/api/v2/coverage`.
- Markdown and CSV coverage reports.
- Automated regression test for sidebar scrolling and coverage content.

## Clarified

The bundled curriculum is extensive but not literally every command, tool version, cloud feature, or company-specific scenario. Safe Real Lab execution remains intentionally narrower than the learning examples for security.
