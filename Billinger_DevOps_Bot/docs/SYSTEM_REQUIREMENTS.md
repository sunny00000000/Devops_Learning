# BILLINGER SYSTEM REQUIREMENTS & SPECIFICATIONS

## Minimum Hardware Requirements
- **CPU:** Dual-core 1.8 GHz x86-64 or ARM64 processor.
- **RAM:** 2048 MB (2 GB).
- **Storage:** 500 MB available disk space for application files, SQLite database, and documents.
- **Display Resolution:** 1280x720 minimum (Scales seamlessly up to 4K 3840x2160).

## Recommended Hardware Specifications
- **CPU:** Quad-core 2.4 GHz processor or higher.
- **RAM:** 4096 MB (4 GB) or 8192 MB (8 GB).
- **Storage:** 2 GB SSD storage (allows large document vault indexing and local backups).
- **Display Resolution:** 1920x1080 Full HD or 2560x1440 QHD.

## Supported Platforms
- **Microsoft Windows:** Windows 10 (20H2+), Windows 11, Windows Server 2019/2022.
- **Linux Distributions:** Ubuntu, Debian, Red Hat Enterprise Linux, CentOS Stream, Rocky Linux, Fedora, Alpine, Arch Linux.
- **macOS:** macOS Monterey (12.0) or higher on Intel and Apple Silicon (M1/M2/M3).
