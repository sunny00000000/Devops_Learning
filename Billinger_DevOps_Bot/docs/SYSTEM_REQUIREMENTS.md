# Billinger Bot v2.9.0 System Requirements

## Lightweight core

| Resource | Minimum | Recommended |
|---|---:|---:|
| Windows | Windows 10 64-bit | Windows 11 64-bit |
| RAM | 4 GB | 8 GB |
| Processor | 2-core x64 | 4-core x64 |
| Browser | Current Edge or Chrome | Current Edge or Chrome |
| Dedicated GPU | Not required | Not required |
| Initial free disk | 250 MB | 1 GB |
| Long-term storage | 2 GB | 5–15 GB for ten active students |
| Internet | Only for online AI, job research, Gmail, and first runtime setup | Stable broadband |

Representative prior server measurements were approximately 124 MB resident RAM. Allow approximately 400–900 MB for the local server and one browser tab, depending on open PDFs, browser extensions, and page count.

## Optional components

| Component | Additional active RAM | Additional disk |
|---|---:|---:|
| WSL Linux labs | About 1–2 GB | About 2–8 GB |
| Small local AI model | About 2–4 GB | About 1.5–3 GB |
| Quantized 7B/8B model | About 6–10 GB | About 4–6 GB |
| Docker Desktop labs | Commonly 4 GB or more | Commonly 10 GB or more |

Gemini, OpenAI API, Groq, and OpenRouter run remotely and do not require a local GPU or downloaded language model.

## Storage growth

Long-term growth comes mainly from project evidence, screenshots, portfolios, resumes, application records, interview analyses, imported documents, and backups. Store at least one backup on a different physical drive.
